The zip code of the sub-app Unzip (T197). `src/` is miniz (MIT), moved here from `apps/unzip/src/miniz` (copy of `apps/ultimate/apps/unzip/src/miniz`, submodule commit `aa2ef5dc`), unchanged.
Since T239.3 D60 it is no library of any app: `apps/unzip/Makefile` compiles `src/*.c` and `miniz_lib.cc` into the image of `unzip.u2a`, which carries the zip code (about 350 KB of source) and needs the base only.
`miniz_lib.cc` returns the call table of `zip_lib.h` as `miniz_table()`; `glue.cc` of the sub-app takes it. A core's app starts `unzip.u2a` for the action and frees it afterwards; the core apps and the host app link no miniz.
