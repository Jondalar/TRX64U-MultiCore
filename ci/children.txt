# T174 D4: the children of the push pipeline - the one table ci/orchestrate.py builds its graph from (spec T174 §5 "D4 design").
# The parent (.gitea/workflows/pipeline.yml) dispatches a child only when the plan asks for it (`when`, evaluated in ci/orchestrate.py) and only
# after the children it `needs` are green. A child is one workflow file with one concern; it runs `ci/child.sh <child> <target>`.
#
#   child     workflow       when          needs
#     when:  apps     an app, the app tests or a fundamental file changed (plan apps / tests / fundamental)
#            images   an app changed, or a child that reads the images runs (cor, package)
#            emu      the host or core application changed
#            owners   one child per bench owner (ci/sims.lane) the plan names a bench of, in the run's tier
#            gateware one child per named gateware target: host (host or aux), core:<id> (plan dfx), large:<id> (plan large)
#            cor      feature branch (scope branch): one per named .cor core or large core
#            package  scope full, or the update files are asked for
#            update   ci/select.sh update = yes
#            ue2      ci/select.sh ue2 = yes
#            local    a step of the parent itself (not dispatched), unless docs only
#     needs: a child name; name(=) the same target of that child; name(x) that child with target x; * every other child that is not
#            named after the star with a minus (-update -ue2); [p] after a need: only for targets that start with p. A need that is not in
#            this run's graph is ignored.
lint       -              local         -
apptests   apptests.yml   apps          -
images     images.yml     images        apptests
emu        emu.yml        emu           images
sim        sim.yml        owners        -
vivado     vivado.yml     gateware      sim(=) vivado(host)[core:]
cor        cor.yml        cor           vivado(=) images
package    package.yml    package       * -update -ue2
update     update.yml     update        package
ue2        vivado.yml     ue2           package update
