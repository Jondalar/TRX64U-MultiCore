# T174 D4, T239.1 S6: the children of the pipeline - the one table ci/orchestrate.py builds its graph from.
# On GitHub .github/workflows/pipeline.yml has one job per row (job id = child name): it calls the row's workflow with `uses:`, runs only when the plan
# asks for the child (`when`, evaluated by ci/orchestrate.py outputs) and `needs:` the jobs this table names. A job whose need was red or skipped does
# not start. Each child workflow is one concern and runs `ci/child.sh <child> <target>`.
#
#   child     workflow       when          needs
#     when:  apps     an app, the app tests or a fundamental file changed (plan apps / tests / fundamental)
#            images   an app changed, or a child that reads the images runs (cor, package)
#            emu      the host or core application changed, and update runs (D23)
#            owners   one leg per bench owner (ci/sims.lane) the plan names a bench of, in the run's tier
#            gateware one target per named gateware lane: host (host or aux), core:<id> (plan dfx), large:<id> (plan large). Not a job: the builder
#                     builds the missing keys (T239.1 D11) and releases the environment `bitstreams`, where the jobs that need them wait (D21)
#            cor      feature branch (scope branch): one leg per named .cor core or large core, not a core with an app of its own (T239.5 D13: its .cor
#                     comes from its matrix lane; the work order still names its bitstream, ci/orchestrate.py order_targets)
#            package  scope full, or the update files are asked for
#            update   ci/select.sh update = yes
#            prerelease  the package of a push to main, t239.1 or a v* tag goes to the builds repository (D1; the ref guard is the job's `if`)
#            local    a job of pipeline.yml itself (not a called workflow), unless docs only
#     needs: a child name; name(=) the same target of that child; name(x) that child with target x; * every other child that is not
#            named after the star with a minus (-update); [p] after a need: only for targets that start with p. A need that is not in
#            this run's graph is ignored.
# emu runs after update (D23); its kit takes this run's VIC-20 .cor and host image, no .ue2 (T239.1 step 17). prerelease is the last job, after
# everything that produced a file.
lint       -              local         -

sim        sim.yml        owners        -
gateware   -              gateware      sim(=) gateware(host)[core:]
cor        cor.yml        cor           gateware(=) images

emu        emu.yml        emu           images update
