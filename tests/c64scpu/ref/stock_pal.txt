The suite's references (T241.1), 2026-11-21, of the .prg files as committed with this file.

trx64g: the board's C64 core, run and read over REST (rest.py). The expected values in the programs are these.
c64re: the c64re runtime, model c64-pal (VIC-II 6569, 63 x 312 cycles, 985248 Hz); scpu1 also on c64-ntsc (6567R8,
65 x 263). It differs from trx64g in two places: scpu4, one cycle more in every row (its CIA is a 6526; trx64g and the
c64scpu use the 8521, whose interrupt comes one cycle earlier), and scpu5 condition d, one cycle less (the sprite DMA).
Values that vary from run to run on both: the TOD rate and the $e518 time of scpu1, the spr columns of scpu3 (checked
within 64).
