page settings|Settings|UP/DOWN select    LEFT/RIGHT or RETURN change    V picture
  settings.direct|Direct boot|on|The default core starts at power-on without the menu. C= or fire on port 1 at power-on shows the menu.|
  settings.hdmi|Picture|from the screen: 1920 x 1080|Only what the screen names is offered. A change asks for a key within 8 s, else it goes back. V steps the mode in every view.|
  settings.protect|Protect Flash from updates|on|On: a large core gets the machine with the host and its app (flash 0x000000-0x3FFFFF) locked until power-off. Flash chip ef4018: status registers SR1 34, SR2 01 now.|
  settings.wifi|WiFi|open|Use DHCP or static addresses, the access point list, enter an access point, connect to the last one, disconnect, forget. The cores show the WiFi and switch it on and off.|
  settings.ftp|FTP service|on, port 21, no password|Switches the FTP file service. Stored in host.cfg; the listener follows at once, a connection that is already open ends with its session.|
  settings.esp|Inspect .cfw/.ue2 for ESP32|open|Looks into a firmware file for its ESP32 image set and version. RETURN opens the File Browser; pick the file there. Reads the file only, writes nothing.|
  settings.cores|Cores and ROMs|open|Each core's folder, its ROM files and saves; what belongs to no core and what is there twice. Deletes the files that belong to no core.|SEL
  settings.report|Bug report|20261030-140510.txt|RETURN writes report/<date-time>.txt on the SD card, else on a USB stick: versions, settings, the cores in the menu and the last log lines. No passwords or keys. The same text is at /v1/report.|
