### Core move: zx (2026-11-25)

Moved with `tools/core_move.py` and the core-move skill (T239.5 D16, lane B, second core). Branch `t239.5-cores-b`. The ZX Spectrum is a large core (`cores/zx/mono/core.toml`, no `core.toml` of its own).

- **Commits by phase.** `650507adb` library (`zx.cc`, `zx_regs.h`, `zx_snap.*` moved; copies of `hk_defaults.h`, `tape_deck.*`, `tape_pulses.*`), TOML A, TOML B, `desc.toml` by name, removal from the shared app (`table.cc`,
  `cores.h`, the board Makefile, D24 ledger and targets, `check_core_id.py`, `release_notes_mc.py`, `cores/zx/mono/core.toml`, `coreapp/README.md`, comments of `cpc_regs.h`, `tape_deck.h`, `zx_snap.py`);
  `8595773d9` tests (`zxapp` units, shared builds without the core, keywalk goldens, rtl_check case, `check_no_rom.py`).
- **TOML A numbers.** The emitter's first form (full 64 KiB scan, 18 min on this Mac): 11 blocks, 52 properties, 24 of them unnamed. By hand: 10 blocks (`ident`, `irq`, `ddr_cal`, `geom`, `machine`, `video`, `win`, `snap`, `tape`, `inject`),
  38 properties, all named, no `# TODO` left; `rtl_check check`: "10 block(s), 38 properties agree". The emitter's byte runs became counted properties (`snap.dir` 27 bytes, `snap.ay` 16, `inject.keys` 5; the app writes them byte by byte as
  `ZX_SNAP_DIR + k`). `geom.frame_clks`, `lines`, `pix_w` are 16 bit at 031, 035, 037 (the RTL reads those bytes; 030, 033 and 034 are constant 0 and have no read). Page 6 (0x101A6000, the host's pixel layer) is not described: the
  core's code does not use it and the host's TOML A owns that layer.
- **rtl_check source list.** `core_toml.py sources zx` names the whole `cores/zx` tree including `mono/host` (the flat build's copy of the host); `cores/zx/app/rtl_check_sources.tcl` names the core's own files (`gen`, `layer2_zx.v`, `rtl`, `shared`,
  `trx`) only. The emitter wrote the first form with `mono/host`; the check agrees without it.
- **Registers by number.** `zx_regs.h` names every register through `drvtab.h` (`ZX_OFS(DRV_<block>_<prop>_ADDR)`, masks `DRV_*_MASK`, reset values `DRV_video_fb_*_reset`); the literal `& 0x08` of the model bit in `zx.cc` became `ZX_ST_M128`.
  `desc.toml` names its registers as `"block.property"` (`video.fb_latest`, ..., `machine.status`) and the two reset values as `video.fb_base.reset`, `video.fb_stride.reset`. `rtl_check.py lint-src` over `zx.cc`, `zx_regs.h`, `zx_snap.cc`:
  "no literal I/O address in 3 file(s)". The numbers of `test_zx.cc` and `test_boot_zx.cc` stand (344 x 280, x0 444, y0 120, `freeze.reg_status == ZX_STATUS`), so the old and the new names have the same values.
- **SDK gaps.** None found by the dry run (10 blocks, 51 registers, `rtl_check` agrees, no compile errors). `core_move.py sdkgaps` reports 2 breaks (`cart_regs`, and all blocks together: `hw.cc:90 DRV_cart_regs_ADDR`), identical to the ddt_novic note: `cart_regs` is a
  block every app has, not caused by this move.
- **Shared files copied (copy rule).** `hk_defaults.h` (6696d1028), `tape_deck.cc`, `tape_deck.h`, `tape_pulses.cc`, `tape_pulses.h` (2fd95fc63) into `cores/zx/app/lib`, each with a first line naming its source path and commit; the originals stay in `coreapp/cores`
  for the CPC and the PET (and, for `hk_defaults.h`, the cores that have not moved). `sdk.toml` lists them as sources/headers of the library `zx` (no shared SDK library covers them). The test harness builds the app's own copies: `zxapp` sets `APPLIB`, which `find_src` tries first.
- **Units, old name -> new name.** `zx`, `zx_snap`, `boot_zx` keep their names (now built as the app: `zxapp`, the group `zx`); the tape converter's test runs twice, `tape` (shared copy, for the CPC and the PET) and `tape_zx` (the app's copy);
  the Spectrum cases of the shared `desc` (golden `menu_zx.txt`, tape keys of T212 D10, joystick ports once of `joyswap`), `descgen`, `hotkeys` (row and the "No joystick swap" case), `memops` (128 KB through the 64 KB window), `media_mounts_engines` (the tape slot)
  and `gen_romreq` (the Spectrum's two ROM rows against `romreq_table.inc`) -> `zx_desc`, `zx_descgen`, `zx_hotkeys`, `zx_memops`, `zx_mounts`, `zx_romreq`. TOML B `tests = { unit = ["zx", "zx_snap", "boot_zx", "tape_zx"], service = ["zx_descgen", "zx_mounts", "zx_romreq"],
  ui = ["zx_desc", "zx_hotkeys"], api = ["zx_memops"] }`. No `ledcores`, `createflow` unit (the core has no LED row and no create task). The shared test files carry `TEST_APP_ZX` branches; the shared `n205` count is 14 now; `test_media_mounts_engines.cc` has
  `MME_OWN_APP` for "an app of its own is its own build", and its drive model and 1541 helpers are out of the Spectrum's build (the app has no drive); `test_hotkeys` uses `portdiag` for the "core without the swap setting" case of the shared unit.
