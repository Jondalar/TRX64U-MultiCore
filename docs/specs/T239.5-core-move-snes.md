## TOML A (`cores/snes/app/gateware.toml`)

Written by hand from `cores/snes/trx/snes_regs.v` (the core's register block at the window `0x101A0000`), not emitted. `python3 tools/toml_a_list.py check snes`: "PASS (155 TOML A bytes, 155 decoded bytes)". 16 blocks, 39 properties, no `# TODO` left. Blocks: `ident` (`[identity] id = "SNES"`), `irq`, `ddr_cal`, `sn_ctrl` (ctrl, system, rom_type), `sn_status`, `sn_frames`, `sn_romaddr`, `sn_stats` (the four cache and stall counters), `sn_fb` (latest, seq, overruns, base, stride), `sn_cart` (cart_base, the two 24 bit masks), `sn_rtc` (eight bytes, `count = 8`), `sn_wr`, `sn_pad` (pad1, pad2), `sn_peak` (peak_dsp, peak_out, hands), `sn_ipl` (64 bytes, `count = 64`, write only), `sn_dspfw` (rewind, data).

- Width: the record takes 8, 16 or 32 bit properties, the RTL decodes three bytes for each mask: `rom_mask` and `ram_mask` are a 16 bit property each and `rom_mask_hi` and `ram_mask_hi` the third byte (the app writes three consecutive bytes, `wr24`).
- Not described: page 6 (`0x101A6000`), forwarded by `snes_regs` to the host's pixel layer (the host's block); the bytes 006/007 of the standard block, which read 0.
- Registers by number: `cores/snes/app/lib/snes_regs.h` names every register through the driver table (`SNES_OFS(DRV_<block>_<prop>_ADDR)`); all 40 registers of the old header have the values of the new names (a `static_assert` file over both headers, compiled against the table made by `core_move.merge_drv`: no error). `desc.toml` names its registers `"block.property"` (`sn_fb.latest` ..., the pad pair `sn_pad.pad1`, `sn_pad.pad2`).
- `rtl_check.py emit` was not run (T264: the list compare is the gate). No case in `tests/rtl_check/test_rtl_check.py` for the SNES (optional, runbook point 4).

## The shared table is empty

`coreapp/src/table.cc` holds no core. What assumed one, and what was done:

- `tests/coreapp`: the shared units keep what is core-independent and run on the made-up core where they need a descriptor: `desc` (table `{ testcore }`: machine line none, no image type, `n205 == 1`, golden `test`, no media flush to hand over), `hotkeys` (generic cases; the S5 row list is a null row that the loop skips), `media_mounts_engines` (the cartridge port's stub core). `descgen`, `keywalk`, `uicover` have no shared unit any more and their test files stop with `#error` when built without an app (`TEST_APP_<CORE>`); `compiled_table.cc` the same; `pad`, `xinput`, `padmenu` too (`#error` without an app).
- `tests/coreapp/cores.txt` lists no core (the group of every moved core is its app build, `CA_APP`); the probe line of the group check in `run.sh` is gone with its only core; `ci/test_apptests.sh` runs its group checks on two scratch groups `demo` and `demo2` (it used `snes` as the real one).
