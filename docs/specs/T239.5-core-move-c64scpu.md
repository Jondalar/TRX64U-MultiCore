# T239.5 core move: c64scpu (2026-11-27)

**Status:** BUILT on branch `core-c64scpu`, not merged; the board test is Alex's. Decision: T239.3 D61 (Alex, 2026-11-27, translated: "It was agreed that ALL cores switch to the SDK and leave the app ... do it!"). Rules: T239.5 D13 (a moved core leaves the old app, its cases in the shared tests become its own app's units) and D17 (no case of a moved core stays in a shared test on a fixture table).

Moved with `tools/core_move.py` and the core-move skill. The C64 with SuperCPU is a large core (`cores/c64scpu/mono/core.toml`, delivery `cfw`). It has the drive window of the C64U's own drive (`c64u_drive_l2`: `mm_drive`, a 1541 or a 1581), so its TOML A carries the blocks `drive_a` (map `cbm1541`) and `drive_wd` (map `wd177x`), as the C128's.

## TOML A (`cores/c64scpu/app/gateware.toml`)

Written by hand, checked against the RTL: 15 blocks, 67 properties, no `# TODO` left; `rtl_check check` with the second bus for the drive window (`drv_io_*`, `0x10020000:0x4000:full`): "15 block(s), 67 properties agree". Blocks: `ident` (`[identity] id = "SCPU"`), `irq`, `ddr_cal`, `core_caps`, `page_id`, `machine`, `status`, `rom`, `cache`, `cold`, `chr`, `perf`, `ram_cnt`, `drive_a` (map `cbm1541`), `drive_wd` (map `wd177x`). Source list: `cores/c64scpu/app/rtl_check_sources.tcl`. Registers by number: `c64scpu_regs.h` names every register through `drvtab.h` (`SCPU_OFS(DRV_<block>_<prop>_ADDR)`); `c64scpu_map.h` holds the numbers the real-ROM bench's PRG writer (`tools/cbm_prg_sim.cc`) needs without the driver table.

**Open SDK gap (recorded, not fixed here):** `core_move.py emit` cannot produce this file. The scan sees a write and a read at every byte of the drive window, so the emitted file is not usable (reproduced on the C128). A hand-written TOML A with the drive window as a second bus is the way for both cores until the emitter reads the window's decode.
