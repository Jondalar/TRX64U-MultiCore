# T79: partial reconfiguration (DFX) trial

Milestone M2, status ✅. Open (one line, as in the TODO table): Done: cores swap through ICAP, return to the host by IPROG works (Atari, NES)

## Description

Split the design into a minimal static layer 1 (clocks, DDR2, RISC-V with USB/SD/flash/Ethernet, ICAP, I/O) and a reconfigurable layer 2 (everything C64-specific); find out whether it fits the XC7A50T, closes timing and what it costs. Spec: [T79-dfx-trial](../specs/done/T79-dfx-trial.md).
