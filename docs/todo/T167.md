# T167 - Overlay redraw shows what lies behind it

Milestone M3, status ✅ done 2026-11-15. Open (one line, as in the TODO table): Done 11-15 (Alex: in builds for weeks)

Spec: `docs/specs/done/T167-overlay-redraw.md`.

## Origin
Alex, 2026-10-31, at the board (translated): "When there is a bar or % numbers in the overlays, they change. While drawing you briefly see
what lies behind the overlay - that is bad. If I have `abcdefghijlkmn` and `00%` lies on top at first, then `00%` becomes `ab%` then `01%`,
and you see the `ab` through it. Right would be `00%`, `01%` - or `00%`, `00%` (overwritten, only what is there, not what lies below), `01%`."
Seen on the restore/update progress pages (host app) and the ROM set loading (core app, Neo Geo/SNES).
