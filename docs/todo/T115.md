# T115 - The host starts a full firmware from a .cfw

Spec: [T115-full-bitstream-cores](../specs/T115-full-bitstream-cores.md). Decision: [ADR-0058](../adr/0058-full-bitstream-cores-by-iprog-from-a-flash-file.md).

Milestone M3, status in progress. Open (one line, as in the TODO table): Merged (trx64 core deleted, D12); board S7: refused .cfw (Claude by FTP, Alex taps it); S4-S6 no record

## Description

The host app lists a `.cfw` beside the `.cor` bundles, checks it (50T `.bit` by IDCODE, application record after the last bitstream), keeps the
bitstream in one scratch file `/Flash/legacy/fullcore.bit`, stages the application in DDR2 under the right address map and hands over with an
ICAP IPROG. Gideon's original and the large TRX64 start the same way; a power cycle returns to the host.
