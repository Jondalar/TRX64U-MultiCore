# T73: Internal IO devices and cartridge IO usage (spec)

Milestone M2, status 📅. Open (one line, as in the TODO table): Rule set 2026-10-18 (only the ranges a cart definition uses); spec, then app

## Description

ADR-0053 proper solution (Alex 2026-10-09): while a cartridge is active no internal device (UCI, Ultimate Audio, REU
registers, ...) answers in $DE00-$DFFF, except in a range the cartridge definition declares free; the cartridge
definitions get an IO usage field. Needs a spec (which devices, which cart types, physical vs emulated, defaults).
