# T89: Apple IIe core as a core in the host/core split

Milestone M2, status ✅. Open (one line, as in the TODO table): Done (Alex 10-30); rest open to contributors

## Description

Port the Apple IIe from https://github.com/MiSTle-Dev/NanoApple2 (donor parts from MiSTer-devel/Apple-II_MiSTer) into layer 2 as a further core behind the T79 host. TREX-internal, ROMs from `/roms/apple2` loaded by the app, plain machine plus Freeze. Video through the host pixel layer (RGB565 from DDR2, 560 x 384, NTSC artifact colours), RAM in block RAM (binding resource: 44 of 50 tiles for the base), floppies served by the app (.dsk/.do/.po/.nib). Spec: [T89-apple2-core](../specs/done/T89-apple2-core.md).
