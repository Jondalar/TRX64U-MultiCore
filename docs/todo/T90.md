# T90: Commodore 264 core (C16, Plus/4)

Milestone M2, status done. Open (one line, as in the TODO table): Done: Lykia, sound, 64K default, 1541 ROM, F7 reset; board confirmed by Alex 2026-10-28

## Description

A C16/C116/Plus/4 core from https://github.com/MiSTle-Dev/C16Nano (FPGATED TED, T65, GPL-3.0, no file with a restricting clause) as a core behind the T79 host: TED on `sys_clk` with an exact 9/10 enable, 64 KB RAM and the ROMs in block RAM (loaded by the application from `/roms/c16`), the 121-colour picture through the host's RGB565 pixel layer (frame in DDR2, dummy VIC-II raster for the scaler lock), our `drive_l2` as the 1541, C64 matrix and joysticks, Freeze by gating the one enable. Estimate about 7,700 LUT placed and 40.5 BRAM tiles (no measurement yet). Spec: [T90-c16-core](../specs/T90-c16-core.md).
