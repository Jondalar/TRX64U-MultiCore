## Board session 2026-10-16: the 020 is the blocker, not a nice-to-have

Alex started the A1200 core with Kickstart 3.1 and got a black screen that keeps resetting. The ROM is
not the problem: `AmigaVision.rom` and `MegaAGS-Kickstart.rom` are byte-identical (SHA-256 6d43840d...),
carry `Commodore-Amiga` and no AROS marker, and say `exec 40.10 (15.7.93)` - genuine Kickstart 3.1,
40.68, the A1200 build. 40.68 is built for the 68EC020; this core is still fx68k, a 68000.

With Kickstart 1.3 the core boots. Alex: "Mit 1.3 bootet er, damit er dann ja aber im Grunde gleich mit
dem 500er" (translated: with 1.3 it boots, but then it is basically the same as the 500). He is right:
1.3 knows nothing about AGA - no AGA screen modes, no 8-plane Workbench - so all that is left of the
second core is 2 MB chip RAM and whatever a game writes into the AGA registers itself.

So P1 (the CPU) is not an improvement to this core, it is the condition for it existing. Recorded here
so the row is not read as "open, optional".
