# T183 - Game Boy Advance core (large core, if it fits the XC7A50T)

Milestone M3, status planned. Open (one line, as in the TODO table): Spec PROPOSED (Alex 11-05): expected no-go (est. 18.5-20k LUT vs 17k usable); synth trial decides, nothing built

Spec: [T183-gba-core](../specs/T183-gba-core.md).

## Origin
Alex, 2026-11-05 (translated): "the last cores that are missing: ... GameBoy (color / advance). Prepare the specs, so we can build them bit by bit."

## Plan (proposed, coordinator; each step small, each with its proving bench; nothing here is decided with Alex yet; step 1 is the go/no-go gate)
1. Gate: `tools/gba_area.sh`, Vivado synth only of the vendored clean machine (no savestates, cheats, shader, 2x path) on the builder; LUT, tiles, DSP; stop above 14,500 LUT (§3 T1); proof: S2 with the 2x-path-left-in control.
2. `tools/vendor_gba.sh` + `NOTICE` (GPL v2, no file headers, BIOS named with its licence) + `tools/gba_gen.py` (GHDL to Verilog, every clock an enable) + T120 row; proof: S1.
3. Clock and timing study on the host's `cpu_clk` with the flat host: enables, multicycle recipe; proof: S6 (report).
4. ARM and Thumb core with BIOS and IWRAM on an ideal memory, our test programs from a small assembler script; proof: S4, S9.
5. Cartridge and EWRAM in DDR2: line caches, hold on a miss, prefetch buffer; proof: S5 (held fraction is the result).
6. PPU into the frame writer (own `pix_layer` copy), sound into the audio ports; proof: S7, S8.
7. Registers, pad, `core.toml` (`delivery = "cfw"`), `mono/build_mono.tcl`, lane `large-gba`; proof: S3.
8. Core application `coreapp/cores/gba.cc`: ROM into DDR2, save type by string scan, saves, optional original BIOS; proof: S10.
9. One board session with Alex's cartridges (SRAM, Flash, EEPROM), batched; proof: S11.

## History
- 2026-11-05 (Alex, translated: "the last cores that are missing: ... GameBoy (color / advance). Prepare the specs, so we can build them bit by bit."): spec `docs/specs/T183-gba-core.md` PROPOSED. `MiSTer-devel/GBA_MiSTer` is GPL v2 (LICENSE file; VHDL without headers). The embedded BIOS (`gba_bios.vhd`) has no stated origin and the README's source is a fork of a disassembly of the Nintendo BIOS: not usable until established; the MIT `Cult-of-GBA/BIOS` is the clean candidate. Fit verdict: expected no-go, 18,500-20,000 LUT (estimate by source size against the measured SNES and by parts) against 17,034 LUT that ever routed (C128, 87.27 percent); block RAM about 50.5 tiles for the core (fits); DDR2 latency 293-693 ns against 119-358 ns bus cycles. Decided by the synth-only trial (S2), not by this estimate. 6 questions in §3a.
- 2026-11-05: put on the core list; spec requested together with T134 (PET), T125 (BBC Micro) and T173 (Game Boy / Color).
