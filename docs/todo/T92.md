# T92: Amstrad CPC core

Milestone M3, status 🔨. Open (one line, as in the TODO table): #17 fixed by T233 (board PASS 11-18); CPC back in the pipeline and the manual (11.13)

## Description

An Amstrad/Schneider CPC core (464/664/6128) for layer 2, ported from MiSTer-devel's Amstrad core (there is no Nano core for this machine). Pixel-layer picture (mid-frame ink changes), RAM and ROM in block RAM, tapes served as pulse streams, DSK disk images served by the app with write-back. TREX-internal like the VC-20 and the Amiga. Spec: [T92-cpc-core](../specs/T92-cpc-core.md). Depends on [T91](T91.md), which builds the shared modules first (T80, YM2149, NCO, key translator, tape pulse engine). Position 8 of the core order in [T79](T79.md).
