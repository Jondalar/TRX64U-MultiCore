# T111 — Format a stick or SD card as exFAT on the board, from the host app

Milestone M3, status ✅ done 2026-11-15. Open (one line, as in the TODO table): Done 11-15 (Alex: in builds for weeks)

## Description

Spec: [`docs/specs/done/T111-exfat-format.md`](../specs/done/T111-exfat-format.md).

An application that formats USB sticks and SD cards as exFAT, running in the host (not in a core). Images larger
than 4 GiB need it: the A1200's `MegaAGS.hdf` is 9,008,283,648 bytes and FAT32 cannot hold it, so T97 S5 cannot run
from the media on the board today (both are FAT32, MBR type 0x0C). Without it every such image needs a PC to
reformat the medium.
