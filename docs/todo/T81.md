# T81: core selector

Milestone M2, status ✅. Open (one line, as in the TODO table): Done: the host app menu (T84, T101); null core not built

## Description

A core bundle (file extension `.cor`) holds a core's partial bitstream (layer 2) and its application (the RISC-V software that belongs to that core). A small LVGL app (the boot app) searches USB and SD for `.cor` bundles and lists them; picking one swaps both, the way softboot works today: the running app sets `core_decouple`, writes the partial bitstream through ICAP, puts the new application into memory and jumps to it (`machine_handover()`); the new application initialises its own core (registers, ROMs, release of `core_decouple`, reset). There is no resident host software: layer 1 is gateware only, every application brings its own drivers (the C64 application is today's Ultimate app; a VC-20 application is the same code base without the C64 parts). Depends on T79 (host/core split, decoupler). The boot chain and the host app are specified in [T84](../specs/done/T84-boot-chain.md); the PoC app `coreload.u2a` (branch t79-coreload of the app repo) loads a partial through ICAP from the running app.
