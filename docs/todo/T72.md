# T72: Quick fix: REU, Ultimate Audio and UCI off while a cartridge runs (physical or .crt)

Milestone M1, status ✅. Open (one line, as in the TODO table): –

## Description

ADR-0053 quick fix (Alex 2026-10-09): the UCI (Command Interface) is off while a cartridge is active, physical (port
armed) or emulated (.crt), on our core. The proper solution with cartridge definitions is T73 (M2).
