## Plan

Rules for every package: an agent per package (at most 2 h; longer: stop with a WIP commit and start a fresh agent), benches on the builder
(`trx64-sim-env:4`, `nice -n 15`, in `timeout`), every bench with a control that fails, `python3 tools/check_todo.py` before each commit, small
commits, stage by name, nothing pushed by an agent. Vivado only where marked. App packages finish only with the RISC-V build
(`ci/trxapps.sh` in `u64-build-env:ci`) and the whole `tests/hostapp/run.sh` and `tests/coreapp/run.sh`. The coordinator reviews every result against
code and spec, merges locally into one integration branch `t164` in the order below and pushes once.

**Start only after Alex has answered Q1-Q6** (they decide table rows, VIC path scope, smoothing and the boundary); Q7-Q11 can be answered while WP1-WP8 run.
