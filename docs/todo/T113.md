Spec: [T113-c128-core](../specs/done/T113-c128-core.md) (DECIDED 2026-10-22; built on branch `t113-build` 2026-10-23, state in 5.5).

Milestone M3, status done. Open (one line, as in the TODO table): Done (Alex 11-14); VDC hang in Busted Boulders: won't do until asked (Alex 11-15)

## Description

A C128 core behind the host's contract. On the core list since 2026-10-12 (T79 history: "and then the C128 too, of
course"), without a number until now. First an analysis: which source (licence), what it costs against `pb_l2`
(LUT, BRAM, DSP), what the contract and the host already give and what they do not (80-column VDC output, Z80,
the 1571, 128 KB RAM, the keyboard's extra keys), and what the application needs. The spec follows from it.
