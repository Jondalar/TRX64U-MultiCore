# T91: ZX Spectrum core

Milestone M3, status merged into T119. Open (one line, as in the TODO table): Merged into T119 (the picture path through the DDR2 frame buffer); its open board finding lives there

## Description

A ZX Spectrum core (48K/128K) for layer 2, ported from MiSTer-devel's ZX-Spectrum (there is no Nano core for this machine). Palette-path picture, RAM and ROM in block RAM, tapes served as pulse streams, snapshots served by the app. TREX-internal like the VC-20 and the Amiga. Spec: [T91-zx-spectrum-core](../specs/T91-zx-spectrum-core.md). Position 8 of the core order in [T79](T79.md). T91 builds the shared modules (T80, YM2149, NCO, key translator, tape pulse engine) first; the Amstrad CPC core ([T92](T92.md)) reuses them.
