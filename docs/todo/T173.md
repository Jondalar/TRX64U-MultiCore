## Plan (proposed, coordinator; each step small, each with its proving bench; nothing here is decided with Alex yet; order after §3a Q1-Q4)
1. Area trial, synth only, on the builder: the vendored machine (CPU, PPU, sound, mappers, no SGB, no colour LUT, no savestates) as a `pb_l2` cell; LUT, tiles, DSP; decides DFX or large; proof: S3 numbers, with the LUT-left-in control.
2. `tools/vendor_gameboy.sh` + `NOTICE` (GPL v3+/MIT/BSD, headerless list) + `tools/gameboy_gen.py` (GHDL to Verilog) + T120 row; proof: S1.
3. CPU, timer, interrupts, DMA/HDMA on an ideal memory with the open boot ROMs; our test programs from a small assembler script; proof: S2, S6.
4. Cartridge path: DDR2 line caches, header registers, mappers MBC1/2/3/5 (plus Q2), hold on a miss; proof: S4, S5.
5. Picture: PPU into the frame writer (`gb_pixw.v`), DMG palette, CGB colour per Q5; proof: S7 (bench).
6. Sound into the audio ports; proof: S8.
7. Registers, pad, `layer2_gameboy.v`, `core.toml`, lane; routed in `pb_l2` (or flat, per step 1); proof: S3 final, S9.
8. Core application `coreapp/cores/gameboy.cc`: file pick, header, ROM into DDR2, saves, RTC; proof: S10 (app tests, RISC-V build).
9. SGB (only if Q3 says yes); proof: its own scenario added to §2 first.
10. One board session with Alex's cartridges (batched, only when 1-8 are green and merged): S11, S7 by eye.
