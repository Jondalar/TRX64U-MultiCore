# T119 — VC-20 and ZX draw into a DDR2 frame buffer of the pixel layer

Spec: [T119-vc20-zx-pixel-layer](../specs/T119-vc20-zx-pixel-layer.md) (DECIDED, 2026-10-23).

Milestone M3, status ✅. Open (one line, as in the TODO table): Done 11-18 (Alex: shipped = done)

## Description

The VC-20 and the ZX core write their picture as RGB565 into a DDR2 frame buffer of the host's pixel layer through the general port `e_*`, as the C264 does, and leave `pix_*` towards the vic_scaler idle. The core app sets the layer up from the descriptor. Cause: the VC-20 menu was cut at the edges on some starts from the host (Alex, 2026-10-23); the Amiga cores on the frame buffer path always fit.
