# T112 — One folder per core with its .cor, settings and ROMs; the ROM search starts there

Milestone M3, status 🔨. Open (one line, as in the TODO table): Layer-2 and large .cor: ROMs and .cfg beside the .cor, benches green; board S1/S2 open

## Description

Spec: [`docs/specs/T112-core-folders.md`](../specs/T112-core-folders.md). The host app finds `.cor` files one folder deeper
(`/cores/<core>/`), the generic application looks for ROMs in the core's own `roms/` first, then searches the trees as today.
