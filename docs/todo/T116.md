# T116 — ZX Spectrum Next core

Spec: [T116-zx-next-core](../specs/T116-zx-next-core.md) (DECIDED, 2026-10-22).

Milestone M3, status 🔨. Open (one line, as in the TODO table): Board passed (Alex 10-28); D11 Auto passed on the board (11-04)

## Description

A ZX Spectrum Next core from the original FPGA source (GPL v3 or later): its 1-4 MB SRAM on DDR2 behind line caches, its SPI SD card answered from an image on the stick, its RGB333 picture through the pixel layer, NextZXOS from the user's own image. First step: the spec and one Vivado synthesis of the `zxnext` entity (spec section 5).
