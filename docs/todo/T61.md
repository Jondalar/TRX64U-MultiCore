## Description

Wall clock (gap audit G05): the app's rtc_dummy.cc keeps the time in RTC_TIMER_SECONDS (0x10060400), set by SNTP and read for every clock and FAT timestamp; our core has no such counter. Decided (Alex 2026-10-04): software, no LUTs: on the TRX64 bitstream rtc_dummy.cc returns the last set time plus FreeRTOS ticks (app branch rtc-sw-app); Gideon's bitstreams keep their counter. App-only (rvlite patch 0006 tried for timing and reverted, run 391).
