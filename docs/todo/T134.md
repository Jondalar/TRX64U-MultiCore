# T134 - Commodore PET core

Milestone M3, status planned. Spec: [T134-pet-core.md](../specs/T134-pet-core.md) (PROPOSED 2026-11-05). Open (one line, as in the TODO table): Spec PROPOSED 11-05: Pet2001_Arty (BSD) base, 3-10k LUT of 18k; Q1-Q13 open (models, disk, keys)

## Plan (proposed, coordinator; each step small, each with its proving bench; nothing here is decided with Alex yet)
1. Vendor Skibo's CPU, PIA, VIA, bus into `cores/pet/rtl` with `NOTICE`; lint line against ROM files; proof: S1, S13.
2. `layer2_pet.v` shell with the 247 ports, register page, RAM 32 KiB, ROM/chargen arrays, 1 MHz enable, test ROM generator; proof: S2, S3.
3. 60/50 Hz retrace line to PIA1 CB1, IRQ; proof: S4.
4. Frame writer (VC-20 `pixw` pattern), 40 columns, scaler lock; proof: S5.
5. Keyboard map 64 -> 80 cells (layout of Q5); proof: S6.
6. Core app `pet.cc`: ROM list and gate, settings, PRG loader with the PET's pointers; proof: S7, S8.
7. Core stage in CI (`core.toml`, `core_sources.tcl`, `ci/targets.txt`), area and WNS; proof: S11.
8. Models: BASIC 4 ROM window `$9000-$FFFF`, 3032/2001 choices; 8032 CRTC and 80 columns only if Q3 says so; proof: S2, S5 again.
9. Disk by the route of Q4; proof: S9.
10. Tape and CB2 sound if Q7/Q8 say so; proof: S10.
11. Board session with the person's ROMs, batched; proof: S12.
