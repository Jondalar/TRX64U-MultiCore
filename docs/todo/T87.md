# T87: CI caches per layer, pipeline without interleaving

Milestone M2, status ✅. Open (one line, as in the TODO table): Done; Q4 settled by D16; the finer split per core is T100

## Description

The Gitea pipeline stops interleaving and cancelling other pipelines (one job per pipeline instead of seven queued stages), and the Vivado caches follow the DFX layers: a host cache (routed static checkpoint + host bitstream) keyed only by the host sources, per-core caches (partial + full image + reports) keyed by host key + that core's sources, retention by branch-HEAD pins plus a short history. A core-only change then implements only the partial against the cached static. The `.cor` bundle carries the host identity so a partial never meets another host. Details: docs/specs/T87-ci-layer-caches.md.
