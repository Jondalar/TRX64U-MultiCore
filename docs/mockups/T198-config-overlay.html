"Save as config..." asks for a name; "Load config..." lists the same configs the boot menu shows and applies one (with the reset the load needs). These two rows replace "Save media set..." / "Load media set..." (question Q2).

Keys

RIGHT opens the overlay on a core row with configs (proposed). RETURN on the row starts plain. In the overlay: RETURN starts the picked config, LEFT or ESC closes.

Wording

One word: "config". "Plain start" is the pick that equals RETURN on the row.

Not drawn

Delete and rename prompts, the start progress overlay (unchanged, title reads "Starting Amiga 1200 - Demo collection"), a list longer than the window.
